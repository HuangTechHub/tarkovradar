# TarkovRadar

An offline, zero-telemetry tactical companion and interactive map suite for Escape from Tarkov built with modern Android, Jetpack Compose, Material Design 3, and Room.

## Features

- **Interactive Tactical Maps**: Multi-floor map navigation, extract conditions, loot spawns, and filterable POIs across all EFT locations.
- **Ballistics & Ammo Guide**: Caliber penetration breakdown against armor classes 1–6, raw damage, and armor damage ratios.
- **Keys & Keycards Tier List**: Location lookup, high-value spawn rates, and slot efficiency metrics.
- **Raid Extract Checklist**: Keep track of required extraction items (flares, rubles, paracord) and extracts.
- **Zero-Telemetry Privacy**: Fully offline, local Room database storage with no ads, tracking, or cloud collection.
